## CodeAlpha Basic Network Sniffer

## Objective
A Python-based network sniffer developed as part of the CodeAlpha
Cyber Security Internship.

## Technologies
- Python
- Scapy

## Features
- Captures network packets
- Displays source IP
- Displays destination IP
- Identifies common protocols
- Displays packet length
- Displays limited payload information

## Installation

pip install -r requirements.txt

## Usage

python network_sniffer.py

Press Ctrl+C to stop the sniffer.

## Ethical Use
This project is intended for educational purposes and should only
be used on networks and systems where you have permission to monitor
traffic.
